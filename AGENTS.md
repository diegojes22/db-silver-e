# db e-commerce
Esta es la Base de Datos para el proyecto de Backend ISC 2026 del ITLP. Esta DB esta preparada para ser de un E-commerce de productos electronicos construida para Supabase.

La base de de datos estara desplegada en supabase, pero el trabajo se realizara en una instancia local de PostgreSQL para evitar comprometer la informacion de la DB.

## Estructura del proyecto
```
./
  models/           # Diagramas de modelado de la base de datos
  src/              
    schema/         # Scripts de creacion para la DB (para MySQL y Postgres)
    insert/         # Insercion de registros e informacion en la DB
    querys/         # Consultas de validacion
  skills/           # Skills para el manejo de Postgres por parte de la IA
```
